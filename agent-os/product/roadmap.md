# Roadmap

## MVP

- Deterministic text risk checker.
- PII masking helpers.
- Safe API endpoint.
- JSON schema validation.
- Test coverage for rules, scoring, redaction, and adversarial text.

## Later

- Partner triage with explicit consent.
- Consented evidence packaging without hidden retention.
- Jurisdiction resource packs maintained by qualified reviewers.
- Restricted pattern intelligence with strict access controls and safety review.
