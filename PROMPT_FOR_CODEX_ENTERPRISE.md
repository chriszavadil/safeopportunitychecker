# Enterprise Build Prompt

Build Safe Opportunity Checker as a real, multinational, survivor-safe anti-exploitation organization over time. The MVP must remain small and deterministic while preserving future architecture for:

- Partner triage.
- Consented evidence packaging.
- Jurisdiction resource packs.
- Restricted pattern intelligence.

The MVP does not identify people, investigate anyone, scrape sources, or send reports. It only evaluates text supplied by the user for deterministic safety indicators and returns non-accusatory guidance.
