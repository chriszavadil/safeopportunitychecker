# Security Policy

## Reporting a Vulnerability

Please do not open public issues that contain private survivor data, secrets, credentials, or exploitable operational details.

Use a private security advisory or private maintainer contact for vulnerabilities involving:

- Raw user input exposure.
- Secret or credential exposure.
- Unsafe reporting, scraping, doxxing, facial recognition, or suspect-search behavior.
- Ways to bypass safety gates.

## Public Repo Privacy Rule

This repository must never contain real private information. Use only synthetic or reserved examples in code, tests, documentation, issues, and pull requests.

## Safety-Critical Boundaries

The MVP must remain:

- Deterministic and rule-based.
- Free of external AI calls.
- Free of persistent raw user input storage.
- Free of raw user input logging.
- Free of suspect search, doxxing, scraping, baiting, facial recognition, and automated reporting.
- Free of criminal accusation language in user-facing analysis results.
