# Production Readiness

## Ready for Preview

- Deterministic risk engine.
- PII masking helpers.
- No-storage web UI.
- `POST /v1/analyze` API.
- JSON schema validation.
- Security headers.
- Request size limits.
- Ephemeral in-memory rate limiting.
- Public PR and issue privacy gates.
- CI safety gate.

## Not Ready Without Owner Review

- Public support email or intake address.
- Privacy policy and terms.
- Country-specific resource packs.
- Partner triage.
- Evidence packaging.
- Restricted pattern intelligence.
- Any deployment that logs request bodies or retains raw submissions.

## Launch Label

Use: `public alpha`.

Avoid claims that imply investigation, official reporting, case intake, emergency response, or legal advice.
